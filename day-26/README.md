## What You'll Learn

- How to write scalar and set-returning functions in PostgreSQL with CREATE FUNCTION and PL/pgSQL
- How parameters, default values, and the IMMUTABLE, STABLE and VOLATILE labels shape a function
- How CREATE PROCEDURE and CALL differ from a function, including COMMIT and ROLLBACK inside a procedure (PostgreSQL 11+)
- How to choose between a function and a procedure - the classic interview question
